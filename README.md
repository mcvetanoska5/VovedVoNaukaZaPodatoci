This repository contains laboratory exercises developed as part of the Introduction to Data Science course at the Faculty of Computer Science and Engineering (FINKI), Skopje.
The main goal of this work is to explore fundamental data science concepts and apply machine learning algorithms to real-world datasets using Python.

Technologies and Tools

Programming Language: Python

Libraries: NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn, TensorFlow (in some labs)

Environment: Jupyter Notebook / Google Colab
